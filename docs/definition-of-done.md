# Definition of Done

A task or user story is considered done when:

- [ ] The required functionality is implemented.
- [ ] The code works as expected.
- [ ] The code has been reviewed by another team member.
- [ ] Unit tests have been written and passed where needed.
- [ ] Integration tests have been completed if needed.
- [ ] All automated tests pass.
- [ ] The user interface works as planned.
- [ ] There are no known major bugs.
- [ ] The changes have been merged into the main branch.
- [ ] Documentation has been updated if needed.

For a user story, all acceptance criteria must also be met.
